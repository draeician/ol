# Summary

ol is a Python CLI wrapper for Ollama, supporting both local and remote instances. It provides enhanced configuration, file injection, vision models, clipboard OCR, and System One decision inference.

**Key Features:**
- System One decision mode (-dc/--dc/--decision) for typed decision inference
  - Decision and decision_vision model categories (tev1, clef-flash defaults)
  - Versioned user-overridable profiles with bundled nsfw and eggs starters
  - Inline boolean questions, clipboard input, batch --each processing
  - JSON/JSON Lines output with interpreted results
  - Capability validation and /v1/systemone transport
- File injection (text/PDF/images)
- Separate text/vision/decision/decision_vision model defaults with temperature control
- Per-type host configuration (text/vision/decision/decision_vision)
- Clipboard OCR (--ocr)
- Model management (list, load forever, unload, loaded models)
- STDIN input support for piping/redirection
- Automatic context-window validation
- Performance metrics (--stats)
- Modelfile saving
- Tab completion (argcomplete)
- Version management

**Essential Decision Workflows:**
```bash
ol -dc ./photo.jpg                              # Default image profile (nsfw)
ol -dc nsfw ./photo.jpg                         # Explicit profile
ol -dc "Is this a nsfw image?" ./photo.jpg      # Inline boolean question
ol -dc ./photo.jpg "Is this image blurry?"      # Question after image
ol -dc eggs ./eggs.jpg                          # Counting profile
ol -dc nsfw -c                                  # Clipboard image
ol -dc nsfw --each *.jpg                        # Batch processing
ol -dc nsfw --json ./photo.jpg                  # JSON output
cat ticket.txt | ol -dc triage                  # Text decision from stdin
ol --dc-list                                    # List profiles
ol --dc-edit nsfw                               # Edit/create profile
```

**Setup for Decision Mode:**
```bash
# Models are separate from chat models
ol --set-default-model decision tev1
ol --set-default-model decision_vision clef-flash

# Optional: set default profiles
ol --set-default-decision-profile text triage
ol --set-default-decision-profile vision nsfw

# Optional: configure decision hosts
ol --set-default-host decision http://server:11434
ol --set-default-host decision_vision http://gpu-server:11434
```
